# ☕ Exercícios de Java — POO e Lógica de Programação

Repositório com exercícios práticos desenvolvidos ao longo das aulas de 
**Java**, cobrindo desde lógica básica até conceitos de 
**Programação Orientada a Objetos**.

---

## 📁 Exercícios

### 🏦 Conta Bancária
Classe `Conta` com encapsulamento, validação de nome e saldo no construtor.

### 🎫 Controle de Atendimento
Sistema de senhas para múltiplos caixas usando atributo estático compartilhado 
entre instâncias e entrada de dados via `Scanner`.

### 🧍 Pessoa + IMC
Classe `Pessoa` com atributos privados, métodos de exibição e cálculo de IMC 
com classificação por faixas.

### 🔢 Exercícios de Lógica
- Verificação de número par/ímpar com `if` e com `switch`
- Verificação de número positivo ou negativo
- Tratamento de exceções com `try/catch` e `NumberFormatException`
